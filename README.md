# 成长积分 · 打卡学习计划

一个给 6 岁孩子（深圳 · 一年级）用的单人打卡网页。单文件 `index.html`，直接打开就能用，不需要服务器、不需要登录。

线上地址：https://benjamin2006.github.io/growth-plan/

## 内容

- **今日**：当天日期、积分环、情绪温度计（5 档）、动态作息时间轴（普通日 / 周一、周三延时课日自动切换）、按类别分组的打卡项、每类得分、「今天只改一件事」提示
- **一周**：项目 × 7 天的可点格子，周一/周三标「延时」，行列合计，左侧项目列固定
- **商店**：可用积分、累计赚、累计花、日均；奖励兑换（零花钱 / 电视 / 罗小黑 / 我的世界 / 公园骑车 / 乐高大件），含每日上限与兑换记录
- **复盘**：本周积分、打卡日均、达标天数、扣分次数；每日柱状、分类得分、情绪分布、按规则生成的家长提示
- **设置**（齿轮直接进入）：孩子信息与作息、项目分值编辑、奖励编辑、云端存储地址、导出 JSON / CSV、导入备份、清空、历史补录、附件上传

## 作息：平日 / 延时日 / 周末

今日页的「今日作息」按星期几自动切换三套时间轴：

- **普通日**：6:50 起床 → 7:55 到校 → 8:20 第一节课 → 15:55 放学 → 17:00 户外 → 18:00 晚餐 → 19:00 作业/复习 20 分钟 → 19:40 阅读 → 20:10 自由 → 20:40 洗漱 → 21:00 情绪复盘 → 21:30 熄灯
- **延时日（周一、周三）**：放学后校内课后服务到 17:30，整体顺延 40 分钟，19:10 作业、19:50 阅读、20:20 自由、20:45 洗漱
- **周末（周六、周日）**：7:30 起床（最多比平日多睡 40 分钟）、8:00 早餐收拾房间、8:40 自由玩、9:30 户外大运动 90 分钟、11:10 回家洗澡、12:00 午餐、13:00 午休或安静阅读、14:00 周末作业/复盘、15:00 兴趣与家务、16:30 屏幕时间（积分兑换，30–45 分钟）、17:20 下楼活动、18:30 晚餐、19:20 家庭时间、20:20 洗漱、21:00 床上阅读、22:00 熄灯

## 深圳小学作息：每半年自动同步

仓库根目录的 `shenzhen-school.json` 存深圳小学的作息口径与学期节点，页面启动时如果**没同步过、或距上次同步超过 183 天、或已过 `recheckAfter` 日期**，会自动拉取一次并覆盖本机作息；设置页「🏫 深圳小学作息 · 自动同步」可看当前使用的学期/数据日期/下次检查时间，也能点「立即同步」。

文件里写的内容有出处：

- 小学上午上课时间一般不早于 8:20、课间 15 分钟（深圳市 2026–2027 学年普通中小学校校历说明）
- 课后服务（校内延时）1–2 课时、结束不晚于 18:00、自愿参加不收费（深圳市义务教育阶段学校课后服务实施意见）
- 一、二年级不布置书面家庭作业；小学生每天睡眠 10 小时
- 学期节点：2026-09-01 开学、2027-01-23 寒假、2027-02-22 春季开学、2027-07-10 暑假

到校 07:55 / 放学 15:55 / 延时到 17:30 是按你家学校当前通知填的，学校临时改时间直接在设置页改；下学期换作息时改这份 JSON（或直接改设置页）即可，不影响已有打卡数据。

## 门禁

设置页不设门禁（家长随时能进）。唯一的验证在**点「保存今日打卡」时**：随机一道三年级数学题（两位数乘法、整除、长方形面积、时间换算、三位数加法），ABC 三选一，答对才提交，防孩子自己刷分。

## 数据存在哪

- 打卡、情绪、兑换、设置：浏览器 `localStorage`
- 附件（截图、作业照片等）：`IndexedDB`，**单个文件 ≤ 10MB，总量 ≤ 100MB**，有占用进度条和下载 / 删除

换设备或清缓存会丢数据，重要记录请定期用设置页的「导出全部数据（JSON）」备份，或换到新设备时「导入备份」。

## 云端保存（可选，手动提交，不用令牌）

设置页「☁️ 云端保存 · 多设备共用」**已经内置了一个可用的存储地址，开箱即用**：getpantry.cloud 的免费公开篮子（100 个篮子、每篮 1.44 MB、不注册、不要令牌）。不需要你填账号、填 PAT。

规则：

- **不自动提交**。当天打卡完成后，点一次「💾 保存今日打卡」（今日页底部或设置页），这时会**弹一道三年级算术题**，ABC 三选一，答对才真正提交（防止孩子随手点）。设置页本身不再设门禁。
- 哪台设备最后提交，云端**当天的数据就以哪份为准**，覆盖同一天，其它日期不动。
- 打开页面会静默拉取云端：历史日期以云端为准；**本机今天已有记录就保留本机，本机今天空着就采用云端今天的数据**（新设备/新浏览器打开也能看到今天）。
- 改以前的某一天，只能在设置页「🗓 历史补录」里改：选日期 → 勾项目 → 保存到云端。

### 想换成自己的篮子（可选）

内置地址是公开篮子，别人也能读、理论上也能写。想独占一个：

1. 打开 [getpantry.cloud](https://getpantry.cloud/)，填任意邮箱，勾人机验证，点「Create a Pantry」，给 pantry 起个名。
2. 创建成功后会给你一串 **Pantry ID**（UUID）。
3. 拼成地址：`https://getpantry.cloud/apiv1/pantry/<ID>/basket/growth`，粘进设置页「存储地址」→ 点「保存这个地址」→ 点「检查云端地址」确认连通。

免费服务的跨域预检偶尔会返回 429，页面会自动等几秒重试（最多 4 次），保存时别急着关页面。

也兼容 `api.restful-api.dev` 的对象地址，或任何自建的「GET 返回 JSON / PUT 覆盖 JSON」端点。注意这类公开地址**谁都能读**，别往里放敏感内容；打卡数据本身不含隐私。

附件（照片）不上云，只在本机 IndexedDB 里。

## 设计依据

「情绪社交」11 项参考 PEERS 社交技能训练思路：情绪命名 → 冷静策略 → 加入同伴前询问 → 接受拒绝 → 冲突修复 → 求助表达。每一项是当场可做的动作，不是性格评价。「需要改进」记录的是行为事实，不是给孩子贴标签。

打印版见随附的 `成长积分表-优化版.xlsx`（4 个页签：每日打卡、作息时间、奖励兑换、使用说明）。`make_xlsx.py` 从 `index.html` 内嵌数据重新生成 Excel，改了网页项目后重跑一次即可。

## 关于长期使用

表格只是工具，不是评估。随年龄增长，建议：

1. 一二年级减少项目数量、动作更具体，分值以 1–2 分为主
2. 三四年级合并同类项，增加自我管理，改为周结算
3. 高年级由孩子自己定目标、家长只做记录；扣分项逐步取消，转为家庭会议讨论后果

如果情绪爆发频率上升、影响上学或睡眠，应继续按医生建议随访，表格不能替代专业评估。
