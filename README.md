# 成长积分 · 打卡学习计划

一个给 6 岁孩子（深圳 · 一年级）用的单人打卡网页。单文件 `index.html`，直接打开就能用，不需要服务器、不需要登录。

线上地址：https://benjamin2006.github.io/growth-plan/

## 内容

- **今日**：当天日期、积分环、情绪温度计（5 档）、动态作息时间轴（普通日 / 周一、周三延时课日自动切换）、按类别分组的打卡项、每类得分、「今天只改一件事」提示
- **一周**：项目 × 7 天的可点格子，周一/周三标「延时」，行列合计，左侧项目列固定
- **商店**：可用积分、累计赚、累计花、日均；奖励兑换（零花钱 / 电视 / 罗小黑 / 我的世界 / 公园骑车 / 乐高大件），含每日上限与兑换记录
- **复盘**：本周积分、打卡日均、达标天数、扣分次数；每日柱状、分类得分、情绪分布、按规则生成的家长提示
- **设置**（需要过门禁）：孩子信息与作息、项目分值编辑、奖励编辑、导出 JSON / CSV、导入备份、清空、附件上传

## 门禁

点右上角齿轮 → 随机一道三年级数学题（两位数乘法、整除、长方形面积、时间换算、三位数加法），ABC 三选一，错 3 次锁 60 秒。目的：孩子不能自己改分。

## 数据存在哪

- 打卡、情绪、兑换、设置：浏览器 `localStorage`
- 附件（截图、作业照片等）：`IndexedDB`，**单个文件 ≤ 10MB，总量 ≤ 100MB**，有占用进度条和下载 / 删除

换设备或清缓存会丢数据，重要记录请定期用设置页的「导出全部数据（JSON）」备份，或换到新设备时「导入备份」。

## 设计依据

「情绪社交」11 项参考 PEERS 社交技能训练思路：情绪命名 → 冷静策略 → 加入同伴前询问 → 接受拒绝 → 冲突修复 → 求助表达。每一项是当场可做的动作，不是性格评价。「需要改进」记录的是行为事实，不是给孩子贴标签。

打印版见随附的 `成长积分表-优化版.xlsx`（4 个页签：每日打卡、作息时间、奖励兑换、使用说明）。`tools/make_xlsx.py` 从 `index.html` 内嵌数据重新生成 Excel，改了网页项目后可重跑。

## 关于长期使用

表格只是工具，不是评估。随年龄增长，建议：

1. 一二年级减少项目数量、动作更具体，分值以 1–2 分为主
2. 三四年级合并同类项，增加自我管理，改为周结算
3. 高年级由孩子自己定目标、家长只做记录；扣分项逐步取消，转为家庭会议讨论后果

如果情绪爆发频率上升、影响上学或睡眠，应继续按医生建议随访，表格不能替代专业评估。
